## What it is

DataTally is the first data-asset plugin for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). It aggregates public usage signals of data assets — downloads, citations, stars — into a single, verifiable profile.

Data has no intrinsic properties. A byte count says nothing about value. The only real signal of a data asset's value is **how it has been used**. DataTally records that usage trail. It does not interpret it.

## What it does

| Tool                | What it does                                    |
| ------------------- | ----------------------------------------------- |
| `search_assets`     | Search data asset profiles by keyword or domain |
| `get_asset_profile` | Get the full usage profile of one asset         |
| `compare_assets`    | Compare two assets within the same signal layer |

Every metric carries its source and fetch time.

## What it never does

- **Never computes value.** No scoring, no valuation, no ranking.
- **Never interprets.** Records are neutral; judgment belongs to the user.
- **Never sells data.** DataTally holds no data assets.

**DataTally does not define what counts as a data asset. The usage record does.**
